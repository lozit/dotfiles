# Neovim — LazyVim

Point de départ identique à Omarchy : [LazyVim](https://www.lazyvim.org/) + thème Catppuccin.

- `Espace Espace` : chercher un fichier · `Espace s g` : chercher dans le contenu
- `Espace e` : arborescence · `Shift+H` / `Shift+L` : onglet précédent / suivant
- `Espace g g` : lazygit · `Espace u w` : retour à la ligne
- `Espace l` : gestionnaire de plugins · `Espace x` : extras LazyVim

Personnaliser : ajouter des fichiers dans `lua/plugins/`.
